Instrucciones para usar y publicar
---------------------------
Archivos incluidos:
- index.html
- styles.css
- app.js
- logo.svg

Cómo publicar en GitHub Pages (desde el navegador):
1. Entra a tu repositorio en GitHub.
2. Haz clic en "Add file" -> "Upload files" y sube todos los archivos dentro de la carpeta del ZIP.
3. Commit changes.
4. Ve a Settings -> Pages.
5. En Source elige Branch: main y Folder: / (root). Guarda.
6. En unos segundos verás la URL: https://<tu-usuario>.github.io/<tu-repo>/

Notas:
- El carrito usa localStorage (no procesa pagos). El botón de WhatsApp abrirá una conversación con el resumen del carrito.
- Puedes editar cualquiera de los archivos directamente en GitHub o descargar el ZIP y modificar localmente.
